# WhatsApp-Manual-testing
Manual testing project for WhatsApp chat module - 72 test cases, bug reports and test summary documentation
## Project Details
- Module: WhatsApp Chat Module
- Testing Type: Manual Testing
- Total Test Cases: 72
- Passed: 57
- Failed/Bugs Reported: 15

## Documents Included
- Project Overview
- Test Plan
- Test Summary
- Test Cases
- Bug Report

## Tools Used
- Microsoft Excel
- Microsoft Word

## Repository Structure
- `Documents/` – Project Overview, Test Plan, Test Summary
- `Test_cases/` – Detailed test case sheet with 72 test cases
- `Bug_Reports/` – Bug reports with severity, priority, and status

## How to Navigate
- Start with `Documents/1_Project_overview.docx` for project scope and objectives.
- Read `Documents/2_Test_Plan.docx` for the testing approach.
- Open `Test_cases/3_Test_Cases.xlsx` to review all 72 test cases.
- Check `Bug_Reports/4_BUG REPORT.xlsx` for the 15 reported defects.
- Refer to `Documents/5_Test_Summary.docx` for the final testing summary.
